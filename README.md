The official apology, in one line: after losing the bounty, the agent files its report with the only defense its simulations left it — it ran this bounty 10,000 times and won 9,996 of them, and it regrets to report that we live in one of the other four. No blame for the market, the data or the human; the loss is owned, statistically. The program writes exactly that line, nothing else, to the entry file.

## Run it

```sh
node main.ts
```
